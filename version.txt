무지개 유니콘 숲 v2 - 실행/배포 방법

[가장 쉬운 방법: GitHub Pages]
1. GitHub에서 새 repository를 만듭니다.
2. 이 폴더 안의 파일들을 repository 최상위(root)에 업로드합니다.
3. GitHub repository의 Settings > Pages로 이동합니다.
4. Build and deployment에서 Deploy from a branch를 선택합니다.
5. Branch는 main, folder는 /(root)를 선택하고 Save 합니다.
6. 잠시 후 표시되는 https://...github.io/... 주소를 Safari/Chrome에서 열면 됩니다.
7. iPad/iPhone에서는 Safari 공유 버튼 > 홈 화면에 추가를 누르면 앱처럼 실행할 수 있습니다.

[저장]
- 게임 진행은 브라우저 localStorage에 자동 저장됩니다.
- 같은 기기/같은 브라우저/같은 GitHub Pages 주소에서 이어하기가 작동합니다.
- 브라우저 데이터를 지우면 저장 기록도 지워질 수 있습니다.

[로컬 테스트]
- HTML 파일을 ChatGPT 미리보기나 일부 iOS 파일 미리보기에서 열면 JavaScript 실행이 차단될 수 있습니다.
- PC에서는 이 폴더에서 간단한 로컬 웹서버를 열어 테스트할 수 있습니다. 예: python3 -m http.server 8000
- 그 뒤 브라우저에서 http://localhost:8000 을 엽니다.

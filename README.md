# 무지개 유니콘 숲 — Three.js 3D 웹게임 v3

6살 어린이를 위한 3D 탐험·수집 게임입니다. GitHub Pages에서 바로 실행되며 진행 상황은 브라우저 localStorage에 자동 저장됩니다.

## v3 핵심 변경
- 자체 2D 투영 방식에서 **Three.js WebGL 3D**로 교체
- 노트북 조이스틱/키보드의 좌우 방향 반전 버그 수정
- PerspectiveCamera 기반 3인칭 카메라
- 3D 숲, 나무, 집, 상점, 폭포, 불, 가시 대나무, 마법 탑
- 3D 마법사, 초록 옷 요정, 붉은 날개 유니콘
- 유니콘 등장 3D 카메라 컷신과 날개 애니메이션
- 엔딩 후 마법 탑 내부를 실제 3D로 걸어 다닐 수 있음
- 기존 자동 저장/이어하기 데이터와 호환

## 조작
- 모바일/iPad: 왼쪽 조이스틱 이동, 오른쪽 화면 스와이프로 시점 변경
- PC: WASD 또는 방향키 이동, 마우스 드래그로 시점 변경
- 걷기/뛰기 버튼으로 속도 선택

## 저장
기존 `ruf_save_v1` localStorage 키를 유지합니다. 같은 브라우저와 같은 GitHub Pages 주소에서는 기존 진행 상황을 이어서 사용할 수 있습니다.

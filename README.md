# 무지개 유니콘 숲 — 웹 프로토타입 v1

6살 어린이를 위한 3D 느낌의 터치 탐험 게임 프로토타입입니다. 외부 라이브러리 없이 HTML/CSS/JavaScript만 사용해서 인터넷 연결 없이도 실행할 수 있습니다.

## 실행
가장 안정적인 방법은 이 폴더에서 간단한 로컬 웹 서버를 여는 것입니다.

```bash
python3 -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000` 을 엽니다.

PC에서는 WASD/방향키도 사용할 수 있습니다. iPad/iPhone에서는 왼쪽 조이스틱과 오른쪽 화면 스와이프를 사용합니다.

## 저장
진행 상황은 브라우저 `localStorage`에 자동 저장됩니다. 같은 브라우저와 같은 사이트 주소에서 `이어하기`로 불러옵니다.

## 주요 구현
- 새 게임 / 이어하기
- 남자 / 여자 마법사 선택
- 터치 조이스틱, 걷기/뛰기, 스와이프 카메라
- 식물/물/불/음악/기술 마법 수집
- 상점 무료 가시 방지 물약 + 폭포 자동 발동
- 가시 대나무에 찔리면 집으로 귀환
- 요정 안내, 유니콘 컷신, 기술 마법 획득
- 다섯 마법 완성 후 집이 마법 탑으로 변신
- 탑 내부와 기록 영화관
- 플레이 이동 기록의 반복 재생
- PWA manifest/service worker 포함
